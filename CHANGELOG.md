## 0.1.0

First public release.

- Menu bar percentage of your most-used Ollama Cloud meter (session / weekly), all meters in the menu.
- Sign in on ollama.com (2FA popups supported) or use an optional API key stored in the macOS Keychain.
- Notifications at 75%, 90% and 100% (once per crossing), and a warning mark in the menu bar from 90%.
- Launch at login, app icon, refresh interval setting.
- Unofficial: relies on the ollama.com settings page and an undocumented usage endpoint.
